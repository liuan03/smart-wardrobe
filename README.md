# 智能穿搭 · Smart Wardrobe

纯前端 AI 穿搭小站。上传衣服/裤子图片，自动抠图、分类（仅上衣/下衣），自由搭配或随机生成无缝竖版穿搭效果图。

## 特点
- **零后端**：数据存在浏览器 `localStorage`，图片用 Canvas 处理，可直接部署为静态站点。
- **自动抠图**：取四角采样背景色，欧氏距离容差 28 切除背景，紧凑裁剪，无白边/灰边。
- **无缝拼接**：上衣在上、下衣在下，上边缘贴合，不按图片尺寸硬拼。
- **两种模式**：`选定穿搭`（先选上衣+下衣再生成）、`随机穿搭`（自动各抽一件）。
- **衣橱管理**：重命名、重新分类、单选/批量删除。
- **竖版输出**：9:16 风格的产物，适合发短视频/朋友圈。

## 运行
- 本地静态服务：`python3 -m http.server 8080`，浏览器开 `http://localhost:8080`
- 或任意静态托管（GitHub Pages / Vercel / Netlify / 对象存储）

## 数据说明
衣物图片仅保存在**你当前浏览器**的 localStorage 中。换设备/清缓存前，请先在衣橱页自行备份（导出功能可加）。
